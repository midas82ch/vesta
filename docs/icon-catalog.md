# Icon-Katalog

Icons ergänzen immer eine sichtbare Beschriftung und transportieren nie allein
die Bedeutung. Die Reihenfolge ist in allen Sprachen stabil; Darija übernimmt
dieselbe fachliche Reihenfolge in RTL-Darstellung.

| Verwendung | Icon-Schlüssel | Bildidee |
|---|---|---|
| Schlafplatz / Wohnen | `shelter`, `housing` | Haus beziehungsweise Haus mit Schlüssel |
| Grundversorgung | `basic-needs` | Schüssel |
| Beratung | `counselling` | Buch beziehungsweise Sprechblasen |
| Opferhilfe / Sucht | `support` | Unterstützende Hand |
| Aufenthalt | `daytime` | Sitz-/Aufenthaltsort |
| Mahlzeit | `meal` | Schüssel oder Teller |
| Lebensmittel | `groceries` | Einkaufstasche |
| Dusche | `shower` | Dusche |
| Wäsche | `laundry` | Waschmaschine |
| Kleidung | `clothing` | T-Shirt |
| Toilette | `toilet` | WC |
| Schliessfach | `locker` | Schrank oder Schlüssel |
| Allgemeine Sozialberatung | `social` | Sprechblasen |
| Geld und Schulden | `wallet` | Portemonnaie |
| Gesundheit | `health` | Herz/Kreuz |
| Psychische Belastung | `mental-health` | Kopf mit Herz |
| Recht | `legal` | Dokument/Waage |
| Alkohol | `alcohol` | neutrales Glas-Symbol |
| Opioide/Heroin | `medication` | neutrales medizinisches Symbol |
| Andere Substanzen | `substances` | neutrale Punkte/Formen |
| Mehrere Substanzen | `multiple` | kombinierte neutrale Formen |
| Nicht sicher | `question` | Fragezeichen |
| Auswahl bestätigt | `check` | Häkchen |

Gestaltungsregeln:

- keine Spritzen, verletzten Körper oder stigmatisierenden Personenbilder;
- Touch-Ziel mindestens 44 × 44 Pixel, tatsächliche Kachel deutlich grösser;
- Auswahl durch Farbe, kräftigen Rand und Häkchen sichtbar;
- Zustand zusätzlich über `aria-pressed` verfügbar;
- bei 320 bis 480 Pixel Breite zwei Spalten ohne horizontales Scrollen.
